## 🎮 Overview

Synthesis runs community-coded C# patchers that automatically generate patches resolving mod conflicts, distributing perks, scaling NPCs, and much more.

Whether you're a newcomer or a veteran, Synthesis (Bethesda patcher) provides the tools you need to get the most out of your gaming mods experience. Designed for Windows and macOS, it delivers a seamless, high-performance workflow.

---

## ✨ Key Features

| Feature | Description |
|---|---|
| **Patcher Library** | One-click install of hundreds of community-coded patchers |
| **Auto Pipeline** | Run all patchers in sequence and regenerate the output patch |
| **Load Order Aware** | Reads your full plugin list for accurate conflict resolution |
| **Safe Sandbox** | Patchers run in isolation with no risk to your existing mods |
